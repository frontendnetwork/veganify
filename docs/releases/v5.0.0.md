# Veganify 5.0.0 release highlights

This release promotes the changes already present in the `v5.0.0-rc.1` release candidate.

## Breaking change

- Biome has been removed. `lint` and `lint:fix` use Oxlint, and formatting uses `bun fmt`.
- Bun is pinned to 1.4.4 for development and CI.

## Fixes

- Repair the PWA manifest icon.
- Add `pt-br` to the Inlang locale configuration.
